# 🛒 QuickCart – Online Grocery Website

QuickCart is a static online grocery shopping website built with **HTML5** and **CSS3**. It offers a clean, user-friendly interface where customers can explore grocery categories and browse popular products.

---

## ✨ Features

- Responsive navigation bar
- Grocery search bar UI
- Attractive hero section
- Grocery categories section
- Popular products display
- Add to Cart buttons (static UI only)
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure and semantic markup |
| CSS3 | Styling and visual design |
| CSS Grid | Category and product layouts |
| Flexbox | Navigation and component alignment |
| Media Queries | Responsive behavior across screen sizes |

## 📌 Project Type

Static Frontend E-commerce Website

> **Note:** This project is a front-end UI only. The search bar and Add to Cart buttons are static and do not have backend or JavaScript functionality.
